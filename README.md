# 📌 Employee Attendance System with QR Code

A full-stack web application for recording employee attendance using QR codes, with automated salary calculation, email notifications, and a comprehensive admin dashboard.

---

## 🌐 English Version (Recommended for GitHub)

### 🚀 Tech Stack
- Backend: Node.js, Express.js, Sequelize, MySQL  
- Frontend: Next.js 15, Tailwind CSS, React Context  
- Database: MySQL (via XAMPP)  
- Additional Features: QR Code Generator, Email Service, Salary Calculator  

---

### 📋 Prerequisites
- Node.js 18+  
- MySQL (XAMPP or standalone installation)  

---

### ⚙️ Installation & Setup

#### 1. Database Setup
1. Start Apache & MySQL in XAMPP Control Panel  
2. Open: http://localhost/phpmyadmin  
3. Create a new database:
   qr_attendance

---

#### 2. Backend Setup
cd backend
npm install
npm run dev

Server runs at: http://localhost:5000

---

#### 3. Frontend Setup
cd frontend
npm install
npm run dev

Application runs at: http://localhost:3000

---

### ✨ Key Features
- QR Code scan for clock-in / clock-out  
- Real-time dashboard statistics  
- Employee management (Full CRUD)  
- Automated monthly salary calculation  
- Attendance & salary reports (exportable)  
- System logs for auditing  
- Email notifications (configurable in settings)  
- Manual entry if scanner has issues
